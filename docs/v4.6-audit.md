## Problemas encontrados

- El hero anterior mostraba una imagen poco clara para ropa urbana premium.
- La primera candidata nueva era mas editorial, pero desktop recortaba demasiado por el aspect ratio.
- La imagen de Jogger Minimal Taupe apuntaba a una URL 404.
- El carrito vacio no recuperaba intencion de compra.
- Algunos badges se percibian mas marketplace que boutique.

## Problemas corregidos

- Hero reemplazado y recompuesto para mostrar outfit/silueta completa en desktop y mobile.
- Imagen rota reemplazada y URLs fallback principales verificadas con status 200.
- Header con mayor peso visual de marca.
- Cards con badges premium y hover mas sutil.
- Empty cart convertido en bloque comercial con productos recomendados.
- Social proof agregado antes de newsletter.
